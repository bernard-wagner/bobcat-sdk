
# 001 no-macro counter

This is the reference counter contract from the stylus-sdk repository. It uses checked math
for the operations. The example avoids using macros to derive the accessors for storage or
the entrypoint so that we can confirm the generated code stays within the target size.

The wasm binary should not exceed 6,403 bytes. `wasm-opt` outputs a 3,938 byte binary. The
reference codebase (Stylus SDK 0.90.2, `no_std`, optimization level `z`) is 16,598 bytes,
and `wasm-opt` reduces it to 11,441 bytes. That target might be generous, because the
reference uses default math for the operation, which implicitly performs wrapping math in
release mode. Using wrapping math, the code generated by bobcat without `wasm-opt` is 6,584
bytes.
